# NEXUS Worldwide Recruitment

Versión independiente del simulador NEXUS Procurement (Unidad 3).

## Archivos
- `index.html`: interfaz principal.
- `styles.css`: estilos y componentes visuales.
- `app.js`: misiones, brief técnico antes de la exploración, preguntas, retroalimentación y progreso.

## Publicación en GitHub Pages
En el repositorio, abre **Settings → Pages**. En **Build and deployment**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/(root)`, y guarda. Cuando termine el despliegue, la URL será `https://angelmaltos03-alt.github.io/nexus-worldwide-recruitment/`.
