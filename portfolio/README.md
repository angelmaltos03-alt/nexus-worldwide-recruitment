# Portafolio profesional · José Ángel Sifuentes Maltos

Sitio estático independiente, construido con HTML, CSS y JavaScript vanilla.

## Ubicación
Este sitio vive en `/portfolio/` para mantener intacta la aplicación NEXUS alojada en la raíz del repositorio.

## Publicación con GitHub Pages
Si GitHub Pages está configurado para la rama `main` y la carpeta `/(root)`, la dirección será:

`https://angelmaltos03-alt.github.io/nexus-worldwide-recruitment/portfolio/`

En caso de que Pages todavía no esté habilitado:
1. Abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/(root)`.
4. Guarda y espera a que GitHub genere el despliegue.

## Archivos
- `index.html`: estructura semántica, metadatos y contenido.
- `styles.css`: diseño responsive, animaciones y hoja de impresión.
- `app.js`: trayectoria desplegable, filtros de formación, búsqueda y navegación.

## Mantenimiento
- Actualiza los datos en los arreglos `experience`, `credentials` y `skillGroups` dentro de `app.js`.
- Revisa fechas, nombres de puestos y evidencia de cursos antes de compartir el perfil como CV formal.
- Los indicadores cuantitativos se muestran como resultados de proyectos específicos compartidos para el portafolio.
- No se utiliza contador local de visitas: una cifra almacenada solo en el navegador no representa tráfico real del sitio.
